# ChurchBooks Project Context

- Native Windows WPF/C#/.NET 10, local-first, SQLite, MVVM.
- Canonical working folder: `D:\Windows Projects\ChurchBooks`.
- No Docker, no Electron/Chromium, no always-on cloud dependency.
- Licensing is last.
- The product must remain usable by non-accountants while preserving accountant-grade behavior.
- The Phase 2 FINAL accounting kernel is frozen unless a later phase explicitly requires a governed accounting change.
