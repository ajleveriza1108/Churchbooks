# Terminology Mapping and Familiar Start

This is an alias/education layer, not a promise that different products model concepts identically.

| Familiar term | ChurchBooks destination | Guidance |
|---|---|---|
| P&L / Profit and Loss | Income & Expense / Statement of Activities view | Search alias; presentation may vary by organization type. |
| Supplier | Vendor / Payee | Alias. |
| Bank match | Reconciliation / transaction matching | Alias. |
| QuickBooks Class | Ministry, Project, Fund, or another dimension | Never auto-equate; ask what the class represented. |
| Xero Tracking Category | Ministry/Department/Location/Project dimension | Never auto-equate with Fund. |
| Spreadsheet tab for Missions/Building | Possible Fund or report grouping | Infer with confidence and require confirmation. |
| Customer in nonprofit migration | Donor/Member/Other payer depending context | Do not silently convert. |

## UX rule
Simple/Pro/Accountant controls feature density. Beginner/Guided/Experienced/Accountant controls explanation depth. They are independent settings.
