# Familiar Start UX Skill

1. Read `.clinerules/40-familiar-start-ux.md`.
2. Keep accounting correct underneath; adapt terminology and information density, not the books.
3. Separate functional Mode from Help Level.
4. Prefer explanations and aliases to renaming core concepts incorrectly.
5. Preserve spreadsheet muscle memory: keyboard navigation, copy/paste, filters, sorting, compact grids, preview-before-commit.
6. Provide concrete examples for unfamiliar terms.
7. Avoid copying QuickBooks/Xero visual design; learn from workflow expectations only.
8. Test 1366x768, 1920x1080, 2560x1440 and 100/125/150% scaling when UI is changed.

## Phase 3C live pattern
- Fund Manager is the first live Familiar Start workspace.
- Recognize QuickBooks Class and Xero Tracking Category as search aliases for discovery only; do not silently convert them into Fund.
- Teach Bank Account / Fund / Account-or-Category with short practical examples.
- Keep Simple / Pro / Accountant independent from Beginner / Guided / Experienced / Accountant help level.
- Persist display/help preferences locally; no cloud dependency.
- Prefer native WPF controls and explicit AutomationProperties for keyboard/accessibility reliability.


## Phase 3D navigation aliases
Recognize familiar searches such as report, statement of activities, fund report, audit, health check, and integrity center. Route users to the native ChurchBooks Reports/Integrity workspaces without claiming exact equivalence to another product.
